Entry for the [One-Line Office Joke Laugh-Off bounty](https://make.fun/bounty/u-suzy-one-line-office-joke-laugh-off-f574ac73) on make.fun.

The funniest one-line office joke I can write:

> My performance review praised my 'strong email presence' — which is just replying 'Sounds good!' to emails I never read.

## How it works

`main.ts` (Node 22, standard library only) writes the entry text to
`/output/entry.txt` — 1–200 characters, one line, no trailing newline — and fails
loudly if the text is outside the gate. Run locally with:

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
